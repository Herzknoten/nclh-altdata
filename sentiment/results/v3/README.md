# Frozen v3 archive and lexical aggregates

Arctic Shift Reddit records for r/NCL, r/royalcaribbean and r/CarnivalCruiseFans, covering January 2025 through September 2026.
The frozen corpus contained 873,962 raw records and 834,395 eligible records; this folder retains aggregate outputs.
`frame_monthly_volume.csv` groups records by `subreddit`, `month` and `kind`, with `observed_items` and `eligible_items`.
`reconciliation_monthly.csv` and `reconciliation_daily.csv` compare item identities with the preceding collection.
`lexicon/monthly_index.csv` contains `item_index`, `author_index`, vocabulary coverage and author-concentration measures.
`manifest.json`, `frame_audit.json` and `selection_diagnostics.json` record provenance, eligibility and selection checks.
Lexical scores are unvalidated descriptive measures; remote archive completeness is unverified and missing values are not zero.
The `model/` subfolder contains separate model-labelled diagnostics; neither tier establishes passenger satisfaction.
