# Price-chart input tables

All Aboard data prepared for the November 4, 2026 deck refresh, with September and October history retained.
Units vary by table: sailing-cabin observations, departure-month cohorts, lead bins and brand-tier summaries.
Key fields include `departure_month`, `line`, `cabin`, `units`, `snapshot` and first-ask price indexes.
Daily prices are normalized to the first observed ask; each table retains its original aggregation and eligibility rules.
Company curves cover the supplied five brands; completed-peer benchmarks retain the September 14 export.
See `manifest.json`; legacy `oct20` momentum column names refer to the November 4 cutoff in this refresh.
