# Close-in price-cut comparisons

All Aboard asking-price histories through November 4, 2026, for Norwegian, Royal Caribbean and Carnival.
The primary window is October 20-November 4; earlier rolling windows provide descriptive comparisons.
The unit is a sailing with the same cabin categories at both endpoints and quotes no more than three days old.
Key columns are `W`, `X`, `population`, `line`, `n_sailings`, `share_cut_pct` and `gap_pp`.
The main cut threshold is a net decline of at least 5% in the median cabin-basket change; peer brands receive equal weight.
See `window_statistics.csv`, `gap_windows.csv` and `test_variants.csv`; the main window straddles October 29.
The 112.7 MB `sailing_windows.csv` source is omitted under the repository's 95 MB file limit.
