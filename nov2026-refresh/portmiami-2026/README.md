# PortMiami calls and passenger-movement inputs

CruiseTimetables calls for 2026-2027 and Miami-Dade guarantee inputs, reviewed in November 2026.
`calls_ctt_*.csv` contains call-level `date`, `line`, `ship`, `arrive`, `depart` and `passengers`.
`out_calls_movements.csv` adds `brand`, `berths`, `legs` and match fields; `inputs_2026.csv` stores `item`, `value` and `source`.
The charts compare guaranteed movements with modeled 2026 capacity and NCLH quarterly occupancy figures.
The source note reports required occupancy of 103.1% across NCLH brands and 110.4% for Norwegian alone.
Calendar-2026 model capacity and the October-September guarantee year differ; scheduled capacity is not actual passenger traffic.
