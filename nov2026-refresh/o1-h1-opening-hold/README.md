# Opening asks and subsequent holds

All Aboard listing-price comparisons for Norwegian, Royal Caribbean and Carnival.
Vintage: October 20, 2026 dry run; these outputs are a code check, not November evidence.
The unit is a sailing with matched cabins; summaries use `cohort`, `line`, `n_sailings` and percentage changes.
O1 matches comparable prior-year sailings at nearby leads of at least 300 days, combining cabins before sailings.
H1 compares October 5 and October 20 using fresh backward-looking quotes and a fixed cabin basket.
See `2026-10-20/` for `O1_summary.csv`, `H1_summary.csv`, `coverage.csv`, `provenance.json` and `verdict.json`.
