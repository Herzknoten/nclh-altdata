# Alternative-data refresh comparison

`table.csv` compares the October 20, 2026 submission with the November 4 refresh and marked November 5 audits.
Each row describes a dataset, including prices, Reddit, mobile devices, card customers, PortMiami and company filings.
Columns are `Dataset`, `At submission (Oct 20)`, `Now (Nov 4)`, `What moved` and `Read for the long`.
The table summarizes existing studies and distinguishes new observations from corrected denominators or unchanged datasets.
The card and PortMiami entries include November 5 information despite the abbreviated current-column heading.
The final column records the team's evidence interpretation; it is not an independently estimated investment conclusion.
