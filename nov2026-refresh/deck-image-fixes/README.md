# Corrected deck chart images

Seven PNG replacements prepared in November 2026 from the existing deck charts and source data.
Sources are All Aboard price histories, Reddit activity and ConsumerEdge card-customer tables.
Each file is a chart image; filenames identify the original slide and shape, so there are no tabular columns.
Price titles, the Reddit baseline label and a cohort label were corrected while retaining their original data vintages.
Card charts retain Q2 2026 and repair demographic denominators, including Carnival age and MSC wealth.
Original full-resolution dimensions are preserved; Regent's incomplete wealth coverage is shown explicitly.
