# Historical occupancy reference
This note summarizes archived company occupancy disclosures reviewed on September 14, 2026.
Sources were NCLH, Royal Caribbean and Carnival results releases, plus NCLH earnings-call transcripts.
The unit is a company-quarter; measures include occupancy, passenger cruise days and lower-berth capacity days.
Q2 2026 occupancy was 102.4% for NCLH, 110.2% for Royal Caribbean and 104% for Carnival's fiscal quarter ended May 31.
NCLH's archived call guidance was about 104% for Q3 2026 and 99% for Q4 2026.
Occupancy divides passenger cruise days by capacity days; third and fourth guests can take the result above 100%.
Fiscal periods and itinerary mix differ, so cross-company and pre-pandemic comparisons need care.
This README preserves the narrative-only reference; related structured records are in `../nclh-kpis/quarterly_kpis.csv` and `../nclh-loadfactor-model/out/nclh_guidance.csv`.
