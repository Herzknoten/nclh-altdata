# September 14 analysis rerun
Retained momentum outputs from the September 2026 comparison rerun.
Source: All Aboard September 2026 exports, with baseline observation windows ending 2026-09-12.
The surviving CSVs do not record the exact input-run override used for this copy.
Units are sailing and cabin combinations; prices are USD per person per night and summary ratios are dimensionless.
`momentum/out/momentum_by_quarter.csv` contains `line`, `departure_quarter`, `median_ratio`, `units` and `sailings`.
The baseline compares 2026-08-23 through 2026-09-12 with 2026-06-24 through 2026-07-14, requiring five observed days per window.
`momentum/out/momentum_bootstrap.csv` contains sailing-cluster intervals; robustness, daily-index and endpoint-coverage CSVs accompany it.
`momentum/out/regression_q4_2026.csv` retains the Q4 forward-ratio check; no separate Q4 analysis files remain here.
